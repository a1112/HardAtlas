# Domain glossary

| Term                       | Canonical meaning                                                                 |
| -------------------------- | --------------------------------------------------------------------------------- |
| Model / 型号               | Manufacturer product family identity, independent of region or pack               |
| SKU                        | Sellable regional/package variant of a model                                      |
| Revision / 修订版          | Hardware change that can alter specifications or compatibility                    |
| Device instance / 设备实例 | A private, user- or organization-owned physical instance                          |
| Source / 来源              | Origin record with usage rights, retrieval time and attribution                   |
| Evidence / 证据            | A scoped source fragment supporting one fact or decision                          |
| Specification definition   | Stable semantic field such as socket or maximum capacity                          |
| Specification value        | Original, normalized and display forms for one definition and scope               |
| Relation edge              | Versioned, evidenced relation between two normalized entities                     |
| Scan snapshot              | Consent-scoped, point-in-time local hardware observation                          |
| Compatibility rule         | Versioned declarative predicate and explained outcome                             |
| Compatibility report       | Immutable result containing subjects, issues, evidence and versions               |
| Data version               | Atomic published catalog and evidence batch                                       |
| Rule version               | Immutable compatibility rule set used for evaluation                              |
| Project                    | Saved build or deployment intent with slots, goals and constraints                |
| Unknown                    | Required evidence or input is missing/conflicting; never equivalent to compatible |

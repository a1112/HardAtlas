LibreOffice environment lacked the document's Chinese fonts, so Chinese body
text rendered as missing glyphs in the temporary preview. This is a renderer
environment limitation, not a reason to mutate the source. Temporary PDF and
PNG review artifacts are intentionally excluded from the archive.

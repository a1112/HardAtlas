# Atlas universal-encyclopedia UI direction

## Visual language

- Light-to-mid-tone knowledge canvas with a deep navy application shell.
- Teal is the primary action and focus color.
- Compatible, conditional, incompatible, and unknown use green, amber, red, and
  slate respectively, always paired with an icon and explicit text.
- Inter and Noto Sans SC, tabular numerals, 8 px layout grid, restrained 12 px
  radii, one-pixel dividers, and compact but breathable data tables.
- No marketing gradients, decorative 3D hardware, glassmorphism, or color-only
  meaning.

## Interaction principles

- Global search is always available.
- Search and taxonomy context are visible when they affect results.
- Source, scope, and update time are one interaction away from every key fact.
- Unknown and conflict states remain visible and actionable.
- Long maintenance flows expose phases, completed modules, cancellation and
  retry.
- AI is embedded in extraction, translation, taxonomy evolution, and proposal
  contexts rather than isolated in a generic chat screen.
